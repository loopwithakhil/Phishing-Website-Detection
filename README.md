# Phishing Website Detection

A Machine Learning based phishing website detection system built using Python, Random Forest, and Streamlit.

## Features

- Detects phishing and legitimate websites
- Random Forest Classification Model
- Interactive Streamlit Web Application
- URL-based feature extraction
- Simple and user-friendly interface

## Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## Project Structure

```
Phishing-Website-Detection/
│
├── app.py
├── feature_extractor.py
├── phishing_url_model.pkl
├── requirements.txt
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```
